# 10 M2 交付说明（单机运营模式）

> 版本 v1.0 · 2026-10-21 · 关联 [05-路线图与风险.md](05-路线图与风险.md) §4、[03-数据模型与接口.md](03-数据模型与接口.md) §2 / §4.11、[04-班表与经济规则.md](04-班表与经济规则.md)

> 形态：**一个应用 + 本机档案**。无服务端、无账号、无公司实体、无角色/邀请码；所有数据与规则都在本机 SQLite，管理入口是客户端内的「运营模式」页面（Q-14 已定）。

## 2. 实现范围

- **机队**：机型模板（含 `A343/BIZJET` 36 座 = 12F/24J 变体）→ 逐机档案（注册号、基地、当前位置、状态机 `ACTIVE/HELD/IN_FLIGHT/MAINTENANCE/RETIRED`、总小时/循环、租赁/自有）。
- **航线/班期/航班实例**：三层结构；班期按起飞机场本地时刻 → UTC（`zoneinfo`，缺 `tzdata` 时回退固定偏移）；按天位图生成未来 7 天实例（每日首次打开自动补生成，另有手动按钮）。
- **抽班**：硬约束（飞机位置 = 首段出发、航段连续、机型匹配、飞机 `ACTIVE` 且无锁）+ 软约束（窗口 1–168h、航段 1–8、总航时 30–1440min、过站 15–240/30–1440min）；返回 1–3 个候选并回显约束；`candidate_token` 为 HMAC 签名的 5 分钟短时凭证，确认时二次校验。
- **锁定/重抽/取消/过期**：飞机 `HELD` + `aircraft_lock`；`roster_leg.flight_instance_id` 部分唯一索引防重复占用；首段前重抽无冷却/费用/次数；首段后不设总时限；取消/过期写失约计数与罚金账本。
- **配载**：开始航段时用 seed 生成并固化（`load_sheet`），支持 `AIRLINER`（95% 客座率/两舱/货邮）、`BIZJET`（整机包机费，不套干线客座率）、`VIP`（无收入）、`CARGO`（只算货邮）；重量按 OEW/ZFW/MTOW 削减。
- **结算**：落地后用实际航时/油耗/距离重算收入与 8 项成本（燃油/起降/地面/机组/维护/租赁/空管/保险），按开始时的 `economy_snapshot` 应用异常策略，写 `settlement` + `ledger_entry` 并同事务更新余额、飞机位置/小时/循环、航班实例与班表状态。
- **异常策略**：`ACCEPT/REJECT/WEIGHTED/REVIEW`；数据缺口按每 10min −5%（上限 −30%，最低系数 0.4）、加速分档（2–4x −20%、4–8x −50%、>8x 拒绝）、暂停 >20% −10%、瞬移拒绝、油量跳变/轨迹距离/轨迹缺失复核；`reject_cost_mode`（FULL/DIRECT_ONLY/NONE）、`review_advance_ratio`（0–0.5）、`scope_mode`（COMPANY_ONLY/ALLOW_OVERRIDES，机型 < 单机覆盖）。
- **运营规则**：草稿 → 预览（100 班合成：平均/中位利润、载客率、亏损比例、破产概率，另附策略系数）→ 发布（乐观锁 `expected_version`，冲突 409）→ 版本列表/回滚 → 审计（before/after + 原因）。
- **账本**：只追加；每条含 `balance_after`；`CAPITAL` 初始资金入库，`reconciled` 校验 `balance == sum(amount)`。
- **单实例**：`create_app` 获取文件区域锁；重复启动打印明确中文提示并以退出码 2 结束（可用 `AOC_SINGLE_INSTANCE=0` 关闭，供并行冒烟）。

## 4. 运行方式

```powershell
# 开发
cd apps/client; npm install; npm run build; cd ../..
python -X utf8 apps/aoc-core/main.py --port 8765 --home "$env:LOCALAPPDATA\AOC" --static-dir apps/client/dist --open

# 演示数据（也可在「运营概览」点「生成演示数据」）
curl -X POST -H "X-AOC-Token: <token>" http://127.0.0.1:8765/local/ops/seed

# 端到端冒烟（SimLink demo，无需 MSFS）
python -X utf8 tools/smoke_m2.py
```

页面：`/ops` 概览 · `/ops/fleet` 机队 · `/ops/network` 航线与班期 · `/ops/fly` 飞行执行（页签：`/ops/roster` 抽班、`/ops/free` 自由飞、`/ops/execute` 配载与执行） · `/ops/finance` 财务（页签：`/ops/settlements` 结算、`/ops/ledger` 账本） · `/ops/rules` 运营规则 · `/ops/review` 复核队列。

客户端细节：

- **当前状态条**：顶部常驻「空闲 / 地面等待 / 飞行中」（`/local/ops/status` 每 2s 轮询），点击跳到对应页面；「运营概览」首格同样可点。
- **呼号与航班号前缀**：运营概览顶部「本机档案」卡片（右侧「设置」）展示档案信息，并可改「自由飞呼号前缀」（`callsign_prefix`，默认 `AUV`）与「抽班航班号前缀」（`flight_prefix`，默认 `AOC`）；示例随输入实时联动（输入 `ABC` 即显示 `ABC → ABC123`）。改航班号前缀会同步改写班期与未开始实例的航班号，`/ops/*` 的候选与班表航段都显示呼号。
- **自由飞出发机场**：`/ops/free` 的出发机场下拉只列「当前有可用飞机」的机场（机队位置去重），无机队的机场不出现；选定机场后再列该机场可用飞机，避免先选到空机场才发现无飞机。
- **自由飞计划起飞时间**：`/ops/free` 表单新增「计划起飞时间」（本地时区显示、UTC 提交）；留空默认当前时间 + 50min，领取后写入 `free_flight.dep_time_utc`，执行页「计划起飞」直接显示。
- **推出前 ZFW 校验**：执行页点「开始记录」前，取 SimLink `TOTAL WEIGHT` − `FUEL TOTAL QUANTITY WEIGHT`（均为磅，×0.45359237 转 kg）算出 ZFW；低于配载单 `zfw_kg` 时弹出提示「实际 ZFW 低于配载单，可能漏装旅客/货物」，确认后可继续，差异写进飞行记录（不阻断）。没有 `ZERO FUEL WEIGHT` SimVar，`FUEL TOTAL QUANTITY` 是体积、不能替代燃油重量。
- **执行页实时状态**：飞行中显示地速/表速、高度（气压/AGL）、经纬度、ETE 与 ETA；每 2s 轮询 `/local/ops/flight-status`（取 SimLink 最新采样）。ETE = 剩余大圆距离 ÷ 地速，地速 <50kt 或未起飞显示「—」。
- **SimBrief**：抽班航段、候选班、自由飞锁定卡与执行页（开始记录前）都有 SimBrief 按钮，按起降机场 + 机型 + 呼号预填；呼号拆成 `airline` + `fltnum`（SimBrief 不认 `callsign`）。点击后由 `POST /local/system/open-external` 交给**系统默认浏览器**打开（webview 内不再新开窗口），后端不可用时退回 `window.open`。
- **SimBrief 配载（manualzfw）**：班表/自由飞/已开始的航班走 `GET /local/ops/legs/simbrief`，URL 带 `reg` 与 `manualzfw`（千磅、保留 3 位 = ZFW kg × 2.2046226 ÷ 1000；配载 = ZFW − OEW，即旅客+货物+邮件）；**不再传 `payload`/`pax`/`cargo`**，也**不预填高度**（不发 `fl`）。AOC 侧配载 seed 与航段绑定（`roster-<leg_id>` / `free-<free_id>`），开始前后展示一致，结算不受影响。
- **取消已开始的航班**：执行页右上「取消本次航班」（`POST /local/ops/tasks/abort`）→ 停止录制（若在录）、作废本段与剩余航段、班表置 CANCELLED、释放飞机、不结算。同时修复：中止录制现在也会走运营钩子，不再留下无法取消的残留任务/飞机锁。
- **财务**：`GET /local/ops/finance/summary` 给总计 + 本周/本月/今年 + 近 6 个月；财务页不再展示账户余额与对账（余额仍见运营概览）。

## 5. 已知限制

1. **安装包需要重建**：`out/AOC-0.1.0-x64-setup.exe` / `.msi` 仍是 M1 构建产物，不含运营页面；便携 ZIP 已按 M2 重新生成。出安装包前按 [09](09-M1交付说明.md) §4 重新执行 `npx tauri build`，并按 [08](08-便携包与测试清单.md) §4.4.1 改为自包含 sidecar（D-30）。
2. **单机即权威**：本机改库视为用户自选作弊，不做对抗（R-24）；服务端校验、多人锁顺延 M3。
3. **飞行员覆盖未实现**（M2 无账号）：`scope_mode=ALLOW_OVERRIDES` 只支持机型/单机覆盖；覆盖条目在客户端「运营规则 → 异常与结算策略 → 覆盖条目（JSON）」里维护（默认 `COMPANY_ONLY`）。
4. **班期时区**：使用 `zoneinfo`；Windows 上若未安装 `tzdata` 会回退固定偏移（无 DST），`requirements.txt` 已加 `tzdata`。
5. **成本口径简化**：停机费固定按「前 2h 免」不单独计（参数保留但当前不扣）、备降/坠机/复飞按运行事件表处理但 M2 不建独立状态机；保险按收入比例。
6. **演示数据的飞行时间轴被压缩**：SimLink `--demo` 用加速时间轴（默认 12x），因此演示航班会被策略判定为高倍加速（>8x 拒绝）；真实 SimConnect 飞行不受影响，冒烟脚本用 2x 验证正常结算。
7. **备份/导出**：档案 zip 含整库（运营表随库导出），但未做「仅导出运营数据」的独立格式。
8. **执行中取消**：若该航段正在录制，取消班表只会释放飞机并取消剩余航段，录制需在「配载与执行」页手动结束；该航段不结算（`ABORTED`）。
9. **SimBrief 配载单位**：配载用 `manualzfw`（千磅、保留 3 位，由 ZFW kg 换算），不使用 `payload`；若 SimBrief 改字段名或单位口径，改 `aoc_route/simbrief.py` 与测试断言即可，AOC 内展示与结算不受影响。
10. **启动仍弹控制台、无托盘**：与 09 §5 第 11 条相同；P-11/A-32 的「无控制台 + 托盘图标 + 安装版直开窗口 / 便携版默认浏览器」尚未实现（见 TODO）。
