# 08 便携包与待测清单

> 版本 v1.0 · 2026-10-19 · 关联 [05-路线图与风险.md](05-路线图与风险.md) §2.1 V-08、[07-M0验证结论.md](07-M0验证结论.md) §1
> 本文回答两件事：**现在交付什么形态的包**、**还有哪些必须人来测、怎么测**。MSVC/Rust 工具链需求见 §4。

## 1. 打包策略：先 ZIP，MSI 留到 release

| 阶段 | 交付形态 | 目的 |
|---|---|---|
| M0 / M1 开发期 | **便携 ZIP**（解压即用，不写注册表） | 让参与者能立刻跑起来，验证功能与性能 |
| M1 验收后 / 对外 Release 前 | **MSI + NSIS 安装包** | 安装体验、开机自启、卸载、WebView2 兜底 |

- 便携包已证明「前端产物可分发、可脱离 Node 运行、性能达标」，安装器不改变这个结论。
- 出 MSI 的唯一硬前置是 **Rust + MSVC 工具链**（§4），约 4–6 GB、首次编译 8–15 分钟。
- 触发 release 打包的条件：① 功能冻结；② 版本号确定；③ 需要给外部用户安装。

## 2. 便携包现状

| 项 | 值 |
|---|---|
| 文件 | `spikes/tauri_map_probe/out/AOC-Map-Probe-portable-0.1.0.zip` |
| 体积 | zip **371 KB** / 解压 **1.3 MB** |
| 内容 | `app/`（index.html + js 1.26 MB + css 66 KB）、`server.py`、`start.bat`、`README.txt` |
| 运行依赖 | Windows 10/11 x64 + Python 3.10+；地图底图需联网 |
| 启动 | 双击 `start.bat` → 自动开浏览器到 `127.0.0.1:5199` |
| 自检结果 | `server_ok=true`、`canvas=1`、**60 FPS**、无致命 JS 错误 |

重建与自检：

```powershell
cd spikes\tauri_map_probe
npm.cmd run build                              # 关键：vite base 必须是 "./"
python -X utf8 tools\make_portable.py          # → out/AOC-Map-Probe-portable-<ver>.zip
python -X utf8 tools\smoke_portable.py         # 解压到临时目录 + 起服务 + 无头 Chrome 冒烟
```

已知限制：**它不是 Tauri 窗口**，是浏览器 + 本地静态服务。因此窗口内存、WebView2 行为、安装/卸载都不在便携包覆盖范围内。

两个踩过的坑（已在 v0.1.0 修正，后续别改回去）：

1. **入口文件名与内容必须纯 ASCII**。最初叫 `启动探针.bat` 且内含中文提示，cmd 按控制台代码页（936）解析 UTF-8 字节，把 `cd /d` 等行拆坏，报出一串 `'in' is not recognized`，并误判 `server.py` 不存在。现为 `start.bat`，提示信息全英文，中文说明只放 `README.txt`。
2. **不要用 `python start.bat` 启动**。`.bat` 是批处理，交给 Python 必然 `SyntaxError`；那种报错与包本身无关。直接双击，或命令行 `.\start.bat`。

### 3.2 现在就能做的（T-01、T-02）

**T-01 跨机冷启动**

1. 把 zip 拷到一台**没装过 Node** 的机器，解压到桌面（路径含空格也测一次）。
2. 双击 `start.bat`。
3. 判据：黑窗口打印 `已启动 …5199`；浏览器自动打开；3s 内出现航线与 `60 FPS` 角标。
4. 反向用例：把 Python 从 PATH 移除 → 应打印中文提示而不是闪退。

**T-02 回放压力**

1. 点 `240×`，让 1 万点跑完（约 8s）。
2. 反复拖进度条 10 次，每次停顿 1s。
3. 判据：航线连续无断裂、光标不跳变；FPS 角标始终 ≥ 刷新率一半；拖动后 < 100ms 完成重绘、无白屏。

## 4. MSVC / 构建工具链（出 MSI 的前置）

### 4.1 为什么必须装

Tauri 在 Windows 上用 **MSVC ABI** 编译 Rust 代码，`rustc` 生成目标文件后需要 `link.exe`（来自 Visual Studio 的 C++ 生成工具）链接成 exe。缺任何一半都会在 `cargo build` 阶段失败，且 **npm 层无法绕过**。当前机器两者都没有：

```
cargo / rustc / rustup  → MISSING
Visual Studio Installer / vswhere → MISSING
WebView2 Runtime 155.0.4283.62 → 已存在（打包时无需再装运行时）
```

### 4.2 需要装什么

| 组件 | 用途 | 体积 |
|---|---|---|
| Rustup + stable-x86_64-pc-windows-msvc | 编译 Rust（Tauri 外壳） | ~1.2 GB |
| VS 2022 Build Tools → **Desktop development with C++**（MSVC v143 + Windows 10/11 SDK） | 提供 `link.exe`、`cl.exe`、SDK 头文件 | ~3–5 GB |

合计约 4–6 GB 磁盘、15–40 分钟（视网速）。编译器只需在**打包机**上装一次，用户机器不需要。

### 4.3 安装（管理员 PowerShell）

```powershell
winget install --id Rustlang.Rustup -e --accept-package-agreements --accept-source-agreements
winget install --id Microsoft.VisualStudio.2022.BuildTools -e `
  --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended" `
  --accept-package-agreements --accept-source-agreements
```

装完重开终端，确认：

```powershell
cargo -V ; rustc -V
& "${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -latest -products * -property installationPath
```

`cargo -V` 有输出且 vswhere 能打印路径，即具备打包条件。若 `cargo build` 报 `link.exe not found`，在「x64 Native Tools Command Prompt for VS 2022」里执行，或先跑 `vcvars64.bat`。

### 4.4 打 MSI / NSIS

配置已就绪（`src-tauri/tauri.conf.json`：`bundle.active=true`、`targets=["nsis","msi"]`、`installMode=currentUser`、`webviewInstallMode=downloadBootstrapper`、中英双语、图标已生成）：

```powershell
cd spikes\tauri_map_probe
npm.cmd run package        # = tauri build
```

产物：

```
src-tauri\target\release\aoc-map-probe.exe                       # 免安装单文件
src-tauri\target\release\bundle\msi\AOC Map Probe_0.1.0_x64_en-US.msi
src-tauri\target\release\bundle\nsis\AOC Map Probe_0.1.0_x64-setup.exe
```

预估：首次编译 8–15 分钟（约 450 个 crate），之后增量 1–3 分钟；MSI 约 3–5 MB。

### 4.5 打包后新增的必测项

| ID | 测试 | 步骤 | 判据 |
|---|---|---|---|
| T-06a | MSI 安装 | 干净 Win10 虚拟机双击 MSI | 无 UAC 报错；开始菜单有快捷方式；启动 3s 内出图 |
| T-06b | NSIS 安装 | 同上，用 `-setup.exe` | 中文安装界面正常，`currentUser` 免管理员 |
| T-06c | WebView2 缺失 | 在未装 WebView2 的镜像上安装 | bootstrapper 自动下载安装成功；断网时应给出明确提示而非白屏 |
| T-06d | 卸载残留 | 卸载后检查 | `%LOCALAPPDATA%\ai.aoc.map-probe` 清空（或按设计保留用户数据并提示） |

| T-06f | 非管理员账户 | 受限用户安装 | 装到用户目录，不写 `Program Files` |
| T-05 | sidecar 互拉 | 安装版启动后杀 `aoc-core` | 前端 3s 内显示断连；后端自动重启；`seq` 续传无缺口；连开 10 次无端口冲突 |

### 4.6 不装 MSVC 的退路

- **保持便携包**：M1 内测够用，代价是没有安装体验与 WebView2 兜底。
- **Electron 打包**：不需要编译器，但偏离 D-03/D-25 的 Tauri 决策，只适合紧急演示。
- 不建议 `x86_64-pc-windows-gnu`（MinGW）：官方非推荐路径，NSIS 打包与 WebView2 行为更容易出问题。

- 新增测试项：先在 §3.1 表格加行，再在 §3.2–§3.6 补「步骤 + 判据」，避免只写名字。
