## 2. 关键数据

**V-03 自适应采样 + BIN_V1**（与固定 1Hz 对照）

| 用例 | 原始点 | 落盘点 | 压缩 | 最大间隔 | 偏差 max/p95 | 体积 | 预算 |
|---|---|---|---|---|---|---|---|
| 2h | 7560 | 1116 | 85.24% | 20s | 27.5m / 0.2m | 14.9KB | 500KB |
| 3h | 11269 | 1342 | 88.09% | 20s | 22.2m / 0.2m | 17.2KB | 750KB |

四项通过标准（≥60% 压缩、≤45s 间隔、≤30m 偏差、体积预算）全部满足，且体积有 30 倍余量——BIN_V1 还能继续加密采样。

**V-05 / V-06 航路链**（navdata AIRAC 2609，加载 81ms；network.pkl 加载 699ms）

| 用例 | 期望 | 实际 | 覆盖 | 高度 | 耗时 |
|---|---|---|---|---|---|
| RJTT→RJAA（AIP fixture） | AIP | AIP | 航路过短不检查 | 未知（DCT 连接） | 781ms |
| ZBAA→ZSSS（图） | GRAPH | GRAPH | PASS | PASS（19 段命中 18 段） | 315ms |
| LROP→LFPG（无高空覆盖） | SIMBRIEF | SIMBRIEF deferred | — | — | 9ms |
| EGLL→KJFK（跨洋） | SIMBRIEF | SIMBRIEF deferred（图航路绕行被拦） | — | — | 9ms |
| 无 navdata | 不崩溃 | AIP + `navdata_unavailable` | — | — | 468ms |

**V-07 地图回放**：10,000 点单条 LineString 每帧 `setData`，无头 Chrome（SwiftShader 软渲染）5s 平均 **60.1 FPS**（撞 vsync 上限），一次性 setData 全量 10,000 点 + 两帧 **26.7ms**，无 JS 异常。

**V-08 便携包**：`dist` + 只用标准库的 `server.py` + `start.bat`，zip **371KB**（解压 1.3MB）。冒烟测试（解压到临时目录 → 起服务 → 无头 Chrome 打开）结果：`server_ok=true`、`canvas=1`、**60 FPS**、无致命 JS 错误（仅 MapLibre 瓦片噪声）。未产出安装包，故"安装/卸载/开始菜单/WebView2 bootstrapper"仍未验证。

**V-10 三进程**：前端（静态 + 同源反代）→ 后端（uvicorn + SQLite）→ 采集器（ack 续传）。采集器被杀后 1.9s 判 offline，重启从 `acked_seq` 续传，14 批 / 280 点无缺口无重复；杀后端后采集器不退出，重启完成剩余批次；10 次冷启动 10 次成功。

## 3. 已确认可用的技术选择

- **自适应采样 + BIN_V1**：不进数据库就能满足体积预算，落盘与回放共用同一模型。
- **航路优先级 AIP → 图 → SimBrief**：三级链路与失败原因（`no_match` / `detour_too_large` / `requires_online`）都能对外解释，前端可按 `provider + warnings` 出提示。
- **MapLibre 增量 `setData`**：不需要分块渲染或 Canvas 自绘，10k 点在全量重绘下仍是 26.7ms。
- **服务端 Session + 双提交 CSRF**：V-09 的 16 项（含伪造 CSRF、越权写、`min_fl > max_fl`）全部按预期拒绝。
- **ack 文件 + 主键幂等**：崩溃恢复不需要分布式事务，重复批次靠 `INSERT OR IGNORE` 去重。

## 4. M0 暴露的问题（M1 前必修）

1. **跨洋图航路绕行 2.07 倍**：EGLL→KJFK 出图 6203.5 NM，大圆仅 2991 NM，且置信度 `high`、覆盖检查 PASS。已加 `MAX_DETOUR_RATIO=1.6` 拦截，改为 `REQUIRES_SIMBRIEF`；M1 还需按航路长度分档（远程 1.25×）并识别 NAT/PACOTS 轨道。
2. **navdata `airway` 表存在 min>max 脏区间**：Y803 为 25000/24500，若直接比较会误判。已按未知处理；M1 上线前要扫描全库统计脏区间比例。
3. **network.pkl 的边没有 min/max FL，且边端点 ident 与 navdata 航段表不对齐**：按 `edge_airway` 反查 22 段全部落空。已改为从航路串还原 `(航路, 起点, 终点)` 再查 navdata，ZBAA→ZSSS 命中 18/19 段。M1 应在建图时就把 `min_fl/max_fl` 写进边。
4. **高度校验曾"空校验通过"**：`checked=0` 时返回 `valid=true`，等于没校验。已改为 `valid=null` + `altitude_unverified` 警告；前端必须把"未校验"和"校验通过"分开展示。
5. **生成成功的航路缺 `simbrief_url`**：只有 deferred 分支带链接，违反 D-20。已在 `generate()` 统一补齐。
6. **心跳 1s 判定过于激进**：本机测试可用，生产应 3–5s，并校验 `seq` 单调性，避免旧心跳覆盖新状态。

## 5. 对 M1 的影响

- **不会阻塞 M1**：采样、地图、航路链、管理端、三进程五项主干都有可运行证据，M1 可按原计划启动个人模式。
- **M1 第一周必须先补的三件事**：
  1. 真实 MSFS 环境跑 V-01/V-02，拿到 10 分钟连接、真实接地 VS/G 与机模比对结论；
  2. 建图阶段把航段 `min_fl/max_fl` 与覆盖索引写进 `network.pkl`，去掉运行期反查；
  3. Tauri 内的 sidecar 握手：随机端口 + token 的握手文件。安装包（MSI/NSIS）按策略留到 release 前，届时按 [08-便携包与测试清单.md](08-便携包与测试清单.md) §4 装 Rust + MSVC 并补 T-05/T-06。
- **M1 可缓办**：Volanta 真实账号接入（有 CSV 兜底，不阻塞主流程）。

## 6. 复现方式

```powershell
python -X utf8 spikes\track_sampling_probe\probe.py       # V-03
python -X utf8 spikes\route_probe\run_probe.py            # V-05 / V-06
python -X utf8 spikes\volanta_probe\probe.py              # V-04（无令牌走 CSV）
dotnet run --project spikes\simconnect_probe -- --replay spikes\simconnect_probe\data\final_approach_rjtt34r.jsonl   # V-01 / V-02
cd spikes\tauri_map_probe; npm.cmd install; npm.cmd run build; python -X utf8 fps_probe.py   # V-07
cd spikes\tauri_map_probe; python -X utf8 tools\make_portable.py; python -X utf8 tools\smoke_portable.py   # V-08 便携包
cd spikes\admin_spa_probe; python -X utf8 probe.py        # V-09
cd spikes\multiproc_probe; python -X utf8 probe.py        # V-10
```

依赖：Python 3.13（fastapi / uvicorn / httpx / playwright）、Node 22、.NET 8、本机 Chrome（V-07 用 `channel="chrome"`，不额外下载浏览器）。
npm 依赖安装建议加 `--registry=https://registry.npmmirror.com`；pip 可用 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

## 7. 限制说明

- 所有 SimConnect 结论来自**回放夹具**（`data/final_approach_rjtt34r.jsonl`，RJTT 34R，80s 进近），不是真实飞行；`--sim` 分支代码完整但未在模拟器内运行。
- 航路 AIP 层使用 **fixture CSV**（`data/aip_routes_sample.csv`），仅验证优先级与校验逻辑，不代表真实 AIP 数据。
- Volanta 未登录，`/api/v1/Flights` 未真实调用；CSV 兜底与诊断文案已验证。
- 相机/帧率测试为无头 Chrome 软渲染，硬件 GPU 环境预期更高；未测 4G 内存/低端核显。
- V-08 只出了**便携包**（浏览器 + 本地 Python 静态服务），未产出 MSI/NSIS：本机缺 Rust 与 MSVC，`tauri build` 无法执行。安装/卸载/WebView2 bootstrapper/原生窗口内存均未验证，"三进程能互相拉起"仍由 V-10 脚本模拟；补齐方式见 [08-便携包与测试清单.md](08-便携包与测试清单.md) §4。
