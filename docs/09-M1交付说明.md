## 2. 实现范围

- **推荐**：按可用时间估算航时（含 15 分钟滑行/爬降），过滤已到达机场、跑道过短、超出机型航程；评分含「从未到访 / 新国家 / 时间匹配 / 跑道余量」。
- **航路**：AIP → 直飞走廊覆盖检查 → Pre-train 图；覆盖不足默认不调图，直接返回 `REQUIRES_SIMBRIEF`；任何失败都生成 SimBrief 链接；SID/STAR/跑道候选与 `.pln` 导出。AIP 使用内置 fixture（明确标记 `fixture-*`），不冒充真实 AIP。
- **记录**：SimLink 帧级采集 → 自动开始（默认发动机运转 10s，可切滑行/离地；预录 10 min 含地面帧）→ 自动结束（连续静止 60s 或停机刹车，到机位才收尾）→ 本地队列；aoc-core 做落地评估、自适应采样、BIN_V2 分段落盘、事件与异常标记，`engine_seconds` / `engine_estimated` 落库；崩溃后可从 raw 队列恢复。
- **回放与报告**：MapLibre 地图 + 高度/地速曲线 + 时间轴/倍速；GPX/CSV/JSON 导出；日志详情按 `LANDING REPORT` 版式呈现（卡片 + ALT/VS/G 曲线 + TDZ），支持导出单文件 HTML 报告。
- **Volanta**：非官方 token 接口（不落盘）+ CSV 导入 + 手动补录；AOC 本地记录始终权威。
- **设置/单位/主题/双语**、首次运行向导、档案 zip 导出/导入、每日数据库备份入口。
- **单机运营模式**（原「公司模式」入口）在 M1 灰显；M2 已实现并在侧栏提供「运营模式」入口（无服务端/无账号），见 [10-M2交付说明.md](10-M2交付说明.md)。

## 4. 运行方式

Tauri 安装包（推荐）：

1. 运行 `out/AOC-0.1.0-x64-setup.exe`（perMachine，需要 UAC）或 `out/AOC-0.1.0-x64.msi`；安装后从开始菜单/桌面图标双击启动，直接出现客户端窗口，无命令行窗口。
2. 应用会以随机端口拉起 `aoc-core`（从安装资源目录读取 Python 源码）和 `aoc-simlink.exe`；用户数据仍在 `%LOCALAPPDATA%\AOC`，与安装目录分离。
3. 首次向导导入 Little Navmap / Navigraph 的 SQLite；没有模拟器时可用：
   `apps\simlink\aoc-simlink.exe --demo --home "%LOCALAPPDATA%\AOC"`。

便携包：

1. 解压 ZIP。
2. 双击 `AOC-portable.exe`：不出现命令行窗口，托盘图标常驻，默认浏览器自动打开本地页面。自包含包（`aoc-core.exe`）不需要 Python；当前 v0.1.0 仍要求 PATH 中有 Python 3.10+。
3. 首次向导导入 Little Navmap / Navigraph 的 SQLite；退出用托盘菜单（会结束 `aoc-core` 与 `aoc-simlink`）。

开发：

```powershell
cd apps/client; npm install; npm run build
python -X utf8 apps/aoc-core/main.py --port 8765 --home "$env:LOCALAPPDATA\AOC" --static-dir apps/client/dist --open
# 另开：apps\simlink\bin\Debug\net8.0\aoc-simlink.exe --demo
```

重新打包：`python -X utf8 tools/make_portable.py --build`。

## 5. 已知限制（不阻塞 M1 内测）

1. **仍依赖系统 Python / .NET**：当前 Tauri 与便携包都调用系统 `python`，SimLink 为 framework-dependent（需 .NET 8），干净机器要先装运行环境。已定 D-30：用 PyInstaller 把 `aoc-core` 打成自包含 `aoc-core.exe`、SimLink 用 `--self-contained true` 发布，用户机器不再需要 Python/.NET；打包命令与验证见 08 §4.4.1。
2. **安装/卸载未在干净机执行**：NSIS 与 MSI 均已生成，仍需按 [08](08-便携包与测试清单.md) T-06 在干净 Windows 上验证安装、卸载残留与 WebView2 兜底。
3. **AIP 自动同步日本 jp-routes**：启动后后台拉取 `https://jp-routes.vercel.app/public/routes.csv`（28 天 TTL，缓存到 `%LOCALAPPDATA%/AOC/cache/aip_routes_jp.csv`，列名 `DEP,DEST,…,Route,…` 已在 `AipProvider` 内做映射）；离线时用旧缓存，从未联网才回退内置 `data/aip_routes_sample.csv`（带 `fixture` 标记并给 warning）。用户仍可用 `aip_path` 覆盖。
4. **航路图改为本地建图**：建图 + Dijkstra 源码已内置到 `packages/aoc_route/aoc_route/net`（运行时副本，不含 `network.pkl`/模型），首次启动用用户 navdata 现场建图（全球约 15 s，后台线程），产物缓存在 `cache/network-<airac>-<指纹>.pkl`；建图失败时图航路自动跳过，不影响 SimBrief 链路。诊断：`GET /local/routes/engine`。
5. **Volanta 非官方接口**：字段/鉴权可能失效；CSV 导入与手动补录是稳定路径。导入会把航班明细、原始 JSON 与轨迹（接口返回时）落库，只增不删；CSV 导出不含轨迹，逐航班轨迹接口可用 `AOC_VOLANTA_FLIGHT_URL`（含 `{id}`）配置。
6. **地图底图默认依赖网络**：设置里可切换「离线（内置经纬网）」底图，无需外网；OSM/CARTO/Esri 卫星仍需联网。
7. **SimLink 回归**：真实 SimConnect 10 分钟稳定性、落地指标与机模比对仍建议在 MSFS 实机按 08 的 T-03/T-04 复测；demo 链路已跑通。
8. **日志跑道接地区俯视图**：`components/RunwayTouchdown.tsx`（SVG）画出跑道轮廓/内移段、物理入口与着陆入口、跑道编号、入口条纹（8 条）、接地区（TDZ）条纹与 900 ft 瞄准点、中线（入口实线 + 其余虚线）、每 300 m 刻度与米数、接地点与接地后滑跑轨迹（优先 `RUNWAY` 段）、距入口/中心线偏移、100 m 比例尺与图例；横向按米单独放大并标注倍数。跑道宽度取 navdata `runway.width`（英尺→米，缺失时按 45 m 兜底）。数据取 `/local/flights/{id}` 与 `/local/airports/{arr}`；navdata 缺失或跑道号未识别时显示「无跑道数据」，不影响主轨迹回放（A-31）。日志详情已改为「报告优先」：`components/LandingReport.tsx` + `TrendChart.tsx`（ALT PROFILE / VERTICAL SPEED / G FORCE，2%–98% 分位裁剪、TD 竖线），原 `Descriptions`/事件表/备注收进「详细信息」折叠区；`export?format=html` 由 `aoc_core/report_html.py` 生成同样版式的单文件报告（内联 CSS/SVG、无脚本/无外链）。
9. **跑道滑跑轨迹线（已实现）**：SimLink 在跑道窗口（地面 GS ≥ 40kt 或空中 AGL < 100ft）按 0.1s 采样，`track.py` 用 `RUNWAY` 段逐点保存、不抽稀，接地区画出的滑跑线连续（点间距 ≤ 8m）。
10. **跑道内移入口（已实现）**：`aoc_navdata` 读取 `runway_end.offset_threshold` 并换算成米（`displaced_threshold_m`），`landing.py` 以着陆入口为基准算 `threshold_distance_m`；视图把内移段画成斜纹、刻度从着陆入口起算。
11. ~~**启动仍弹控制台、无托盘**~~（已实现）：Tauri release 与 `AOC-portable.exe` 都以 `CREATE_NO_WINDOW` 拉起 `aoc-core` / `aoc-simlink` 并把输出重定向到 `logs/{core,simlink}.log`，托盘菜单提供「打开客户端 / 打开日志目录 / 退出」，关闭窗口最小化到托盘；P-11 / A-32 的人工验收 T-21 于 2026-10-24 通过（安装版 + 便携版，退出后无残留 sidecar）。
12. **SimLink 自动重连**：`SimConnectSource` 改为后台线程状态机（连接 → 收消息 → 断开 → 5s 退避重连），`new SimConnect(...)` 失败、`OnRecvQuit`、`ReceiveMessage` 异常都不再退出或卡住 HTTP 服务；`/status` 带 `reconnect_attempts`、`last_connect_error`，`POST /command {action:"reconnect"}`（前端设置页「重新连接」）可立即重试。所以「先开 AOC 再开 MSFS」也会在 5s 内自动连上；飞行中模拟器退出再进，日志里会记录 `sim_disconnected` / `sim_connected` 事件与数据缺口。回调频率平时 `SECOND`（1 Hz），跑道窗口临时切 `SIM_FRAME`；采样只保留最近 2 万点 + 1 Hz/10 min 预录 + 复用 JSON 缓冲写盘（D-26）。自动开录默认从发动机启动起算（`auto_start_on`），预录里的地面帧一起进日志；自动收尾改为「连续静止 60s / 停机刹车」，并在 core 判定后补发 `stop_recording`。
