## 2. 实现范围

- **推荐**：按可用时间估算航时（含 15 分钟滑行/爬降），过滤已到达机场、跑道过短、超出机型航程；评分含「从未到访 / 新国家 / 时间匹配 / 跑道余量」。
- **航路**：AIP → 直飞走廊覆盖检查 → Pre-train 图；覆盖不足默认不调图，直接返回 `REQUIRES_SIMBRIEF`；任何失败都生成 SimBrief 链接；SID/STAR/跑道候选与 `.pln` 导出。AIP 使用内置 fixture（明确标记 `fixture-*`），不冒充真实 AIP。
- **记录**：SimLink 帧级采集 → 自动开始（空中 5s，含 20s 预录）→ 自动结束（接地 30s、GS<5kt）→ 本地队列；aoc-core 做落地评估、自适应采样、BIN_V1 分段落盘、事件与异常标记；崩溃后可从 raw 队列恢复。
- **回放**：MapLibre 地图 + 高度/地速曲线 + 时间轴/倍速；GPX/CSV/JSON 导出。
- **Volanta**：非官方 token 接口（不落盘）+ CSV 导入 + 手动补录；AOC 本地记录始终权威。
- **设置/单位/主题/双语**、首次运行向导、档案 zip 导出/导入、每日数据库备份入口。
- **单机运营模式**（原「公司模式」入口）在 M1 灰显；M2 已实现并在侧栏提供「运营模式」入口（无服务端/无账号），见 [10-M2交付说明.md](10-M2交付说明.md)。

## 4. 运行方式

Tauri 安装包（推荐）：

1. 运行 `out/AOC-0.1.0-x64-setup.exe`（perMachine，需要 UAC）或 `out/AOC-0.1.0-x64.msi`；安装后从开始菜单启动 AOC。
2. 应用会以随机端口拉起 `aoc-core`（从安装资源目录读取 Python 源码）和 `aoc-simlink.exe`；用户数据仍在 `%LOCALAPPDATA%\AOC`，与安装目录分离。
3. 首次向导导入 Little Navmap / Navigraph 的 SQLite；没有模拟器时可用：
   `apps\simlink\aoc-simlink.exe --demo --home "%LOCALAPPDATA%\AOC"`。

便携包：

1. 解压 ZIP。
2. 双击 `start.bat`（需要 PATH 中有 Python 3.10+）。
3. 首次向导导入 Little Navmap / Navigraph 的 SQLite。

开发：

```powershell
cd apps/client; npm install; npm run build
python -X utf8 apps/aoc-core/main.py --port 8765 --home "$env:LOCALAPPDATA\AOC" --static-dir apps/client/dist --open
# 另开：apps\simlink\bin\Debug\net8.0\aoc-simlink.exe --demo
```

重新打包：`python -X utf8 tools/make_portable.py --build`。

## 5. 已知限制（不阻塞 M1 内测）

1. **安装包不内置 Python**：Tauri/便携包都调用系统 `python`，干净机器需先装 Python 3.10+；后续可用 PyInstaller 把 aoc-core 打成 sidecar。
2. **安装/卸载未在干净机执行**：NSIS 与 MSI 均已生成，仍需按 [08](08-便携包与测试清单.md) T-06 在干净 Windows 上验证安装、卸载残留与 WebView2 兜底。
3. **AIP 自动同步日本 jp-routes**：启动后后台拉取 `https://jp-routes.vercel.app/public/routes.csv`（28 天 TTL，缓存到 `%LOCALAPPDATA%/AOC/cache/aip_routes_jp.csv`，列名 `DEP,DEST,…,Route,…` 已在 `AipProvider` 内做映射）；离线时用旧缓存，从未联网才回退内置 `data/aip_routes_sample.csv`（带 `fixture` 标记并给 warning）。用户仍可用 `aip_path` 覆盖。
4. **航路图改为本地建图**：`Pre-train/src` 随包分发（只建图脚本，不含 `network.pkl`/模型），首次启动用用户 navdata 现场建图（全球约 15 s，后台线程），产物缓存在 `cache/network-<airac>-<指纹>.pkl`；建图失败时图航路自动跳过，不影响 SimBrief 链路。诊断：`GET /local/routes/engine`。
5. **Volanta 非官方接口**：字段/鉴权可能失效；CSV 导入与手动补录是稳定路径。导入会把航班明细、原始 JSON 与轨迹（接口返回时）落库，只增不删；CSV 导出不含轨迹，逐航班轨迹接口可用 `AOC_VOLANTA_FLIGHT_URL`（含 `{id}`）配置。
6. **地图底图默认依赖网络**：设置里可切换「离线（内置经纬网）」底图，无需外网；OSM/CARTO/Esri 卫星仍需联网。
7. **SimLink 回归**：真实 SimConnect 10 分钟稳定性、落地指标与机模比对仍建议在 MSFS 实机按 08 的 T-03/T-04 复测；demo 链路已跑通。
