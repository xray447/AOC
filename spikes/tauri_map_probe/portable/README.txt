AOC 轨迹回放探针（便携版）v0.1.0
================================

用途
----
M0 技术验证用离线轨迹回放器：把 1 万点航迹压成一条 LineString，每帧用
setData 增量更新，用来验证 Tauri + MapLibre 的渲染方式与体积预算是否成立。
本包是同一套前端代码的便携分发形式（不装 Tauri、不写注册表）。

运行要求
--------
- Windows 10/11 x64
- Python 3.10+（安装时勾选 "Add python.exe to PATH"）
- 看地图底图需要联网（OpenStreetMap 瓦片）；断网也能回放航迹，只是底图空白

启动
----
双击 `start.bat`，浏览器会自动打开 http://127.0.0.1:5199/index.html
关闭黑窗口即结束；端口被占用时会自动顺延（5199→5218）。

不要用 python 去执行 .bat（`python start.bat` 会报 SyntaxError）；想直接跑服务请用
`python server.py`。文件名保持 ASCII 是刻意的：某些 cmd 代码页下中文文件名解析会失败。

界面操作
--------
- 右下角角标：实时 FPS（60 帧均值）
- 倍速：10× / 60× / 120× / 240×，240× 下 1 万点约 8 秒放完
- 进度条：拖动可跳到任意时刻，用于测 seek 后的重绘耗时

这个包能验证什么
----------------
- 单条 LineString + 每帧 setData 在 1 万点规模下是否流畅（V-07）
- 前端产物在无 node/无开发服务器的环境里能否直接运行（V-08 的一半）
- 便携分发包的体积（zip 约 0.4 MB，解压约 1.3 MB）

这个包不能验证什么
------------------
- 安装/卸载/开始菜单/WebView2 bootstrapper（需要 MSI/NSIS 安装包）
- Tauri 原生窗口的性能与内存（WebView2 与 Chrome 行为不同）
- 真实 GPU 下的帧率上限（无头 Chrome 实测为软渲染下限）

常见问题
--------
1) 双击没反应：检查是否装了 Python；或在命令行执行 `python server.py` 看报错。
2) 页面黑屏：确认地址是 127.0.0.1 而不是 file://（file:// 下浏览器禁止 Worker）。
3) 底图灰块：OSM 瓦片被墙或限流，不影响航迹绘制与帧率统计。
